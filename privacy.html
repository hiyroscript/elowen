Privacy Policy

Last updated: September 12, 2026

Elowen is a free collection of browser-based tools. You can use it without an account or providing personal information.

Work stored in your browser

Elowen uses localStorage to save calculator history (up to 500 entries), calculator memory, your current expression and result, and preferences such as angle mode and your explicit light or dark theme choice. This data stays in that browser profile. Anyone with access to the same profile may be able to view it.

Backups are yours

Exported backups download to your device as JSON files. Imports are read and validated locally in your browser. Elowen does not intentionally transmit your calculator history, imported backups, or saved work to an Elowen server. You choose whether and how to share a downloaded backup.

Site hosting and offline files

GitHub Pages serves the website. Like any web host, GitHub may process connection information, including IP addresses and request details, when delivering pages. Its own privacy practices apply to that hosting. Elowen’s service worker caches its own static files for offline use; it does not add saved work to those cached files.

No tracking features

The Elowen application uses no analytics, advertising, tracking scripts, cookies, external fonts, or external data APIs. Local storage and offline caching are used only to provide the features described here.

Control and deletion

You can export or clear saved work on the Your data page. Clearing browser or site data may also remove your work and cached files. Private browsing or storage restrictions can prevent data from persisting. Keep exported backups if you want portable copies.

Changes

This policy may change when Elowen’s features change. The date above identifies the latest revision.
