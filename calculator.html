    How to use the calculator

    Type an expression or use the buttons. Press Enter or = to calculate. Escape clears all; Delete and Backspace edit the expression. Standard browser shortcuts remain available.

    Use parentheses for groups and functions, such as sqrt(16) + sin(30). Powers are evaluated before a leading minus: -2^2 = -4. Exponents group to the right: 2^3^2 = 512. Implicit multiplication is supported, such as 2pi and 2(3+4).

    Percent always divides the preceding value by 100. For 20% of 150, enter 150 × 20%; to increase 150 by 20%, enter 150 × (1 + 20%). Functions use real numbers. Results display up to 12 significant digits; calculations use JavaScript floating-point precision.

    Scientific function buttons wrap a selection or completed result; otherwise they insert a function at the cursor. CE removes the current number or word. MS stores a result, MR inserts it, M+ and M− add or subtract, and MC clears memory.
